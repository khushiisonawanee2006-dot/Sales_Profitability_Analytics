# Sales & Profitability Analytics Dashboard

## 📊 Project Overview

This project is an interactive Sales & Profitability Analytics Dashboard developed using Power BI.

The dashboard helps analyze sales performance, profitability, orders, products, regions, and customer performance to identify important business insights.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Track total orders and profit margin
- Compare sales performance across regions
- Analyze product-wise sales and profit
- Identify top customers based on sales
- Analyze monthly sales and profit trends
- Provide interactive filtering using slicers

## 📌 Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Profit Margin %
- Monthly Sales & Profit Trend
- Sales by Region
- Sales by Product
- Profit by Product
- Top Customers by Sales
- Year-wise analysis
- Region-wise filtering
- Product-wise filtering

## 🛠️ Tools & Technologies

- Power BI

## 🗄️ Data

The sales data was stored and managed using MySQL and connected to Power BI for visualization and analysis.

The dataset contains information such as:

- Order ID
- Order Date
- Customer
- Product
- Region
- Sales
- Cost
- Profit
- Profit Margin
- Year
- Month

## 📈 Key Analysis

The dashboard provides insights into:

- Sales and profit trends over time
- Regional sales performance
- Product performance
- Customer contribution to sales
- Overall profitability
